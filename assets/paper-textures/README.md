# Texturas originales de la ficha

Generadas con la herramienta integrada de imágenes, a partir de descripciones de materiales. Las imágenes aportadas por el usuario se consultaron como inspiración visual; no se incorporaron ni se editaron para obtener estos fondos.

Archivos finales: `parchment.webp`, `worn.webp`, `notebook.webp`, `textured.webp`, en esta carpeta. Se conservó el fondo actual como quinta opción. Los originales generados se convirtieron a WebP, sin cambiar su composición.

## Prompts finales

Cada prompt concatena este prefijo, una descripción y el cierre común:

**Prefijo:** Use case: photorealistic-natural. Create ONE original portrait paper texture asset for a web D&D character sheet background, aspect 2:3.

**parchment:** Ancient parchment in warm pale honey tan. Organic ragged weathered perimeter with shallow cracks, worn layered edges and soft localized shadows within outer 4 percent. Central 90 percent light, even and usable for writing. Fine tactile leathery paper grain.

**worn:** Worn white/off-white character sheet paper, lightly crumpled and repeatedly erased. Realistic soft irregular creases, a few pale gray graphite smudges and rubbed eraser marks mostly near edges, subtle fiber abrasion. Center clean ivory white, bright enough for black printed text. No drawn marks or letters.

**notebook:** Old used school notebook paper, off-white, many realistic fine soft crumple creases, thin faded gray-blue horizontal ruled lines, faint red vertical margin at far left, tiny worn binder holes within leftmost 3 percent. Paper fills frame, no desk. Quiet bright writing surface, no writing.

**textured:** Handmade light cream cotton paper, visible fine fibrous tactile texture with subtle natural flecks and softly irregular fiber patterns. Mostly uniform clean light warm ivory color, no stains or folds, no border.

**Cierre:** Flat orthographic scanned paper surface, full bleed to all four image edges. Real photographic material, natural diffuse illumination. Absolutely no text, numbers, symbols, watermark, UI, objects, desk, page curl or perspective. This is an original design inspired by material descriptions, not a copy of provided reference photos. Details should remain subtle so dense black form text placed over it is highly readable.
